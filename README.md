# air_quality 兰州市空气质量分析与预测

基于 Python 数据挖掘与机器学习的兰州市空气质量时序分析与 AQI 预测项目，完整覆盖数据爬取、数据预处理、探索性数据分析、特征工程、降维聚类、多模型预测与可视化平台开发全流程。

## 项目文档

完整设计报告见：[设计报告.docx](docs/设计报告.docx)

报告包含数据爬取、预处理、EDA 分析、特征工程、聚类分析、机器学习与深度学习预测、可视化平台开发等完整内容。

## 项目背景

兰州市地处西北内陆，南北两山夹一河的河谷地形导致大气扩散条件差，空气质量管控难度大。本项目以兰州市 2014-2026 年逐日空气质量监测数据为研究对象，挖掘污染物时序变化规律与相关性特征，构建多模型 AQI 预测方案，并搭建可视化分析平台。

## 核心功能

**1. 数据获取**
通过爬虫从天气后报网站采集兰州市 2014-2026 年逐日空气质量数据，共 4486 条样本、11 个字段。

**2. 数据预处理**
- 缺失值：数值型中位数填充、类别型众数填充、日期前后向填充
- 异常值：IQR 四分位法截断、CO 业务阈值截断、负值归零
- 一致性修复：AQI 国标范围限制、PM2.5>PM10 逻辑修复、质量等级重校准

**3. 探索性数据分析（EDA）**
描述性统计、质量等级分布、单变量分布、多变量相关性、时序趋势分析。核心结论：PM10 与 AQI 相关系数 0.967，是影响空气质量的首要污染物；冬季 AQI 显著高于夏季。

**4. 特征工程**
构造时间维度特征（年份、月份、季节、星期几、是否周末）和时序衍生特征（AQI_lag1、PM2.5_roll7_mean），共 14 项特征。

**5. 降维与聚类**
PCA 降维至 2 维（累计方差解释率 80.04%），肘部法则确定 k=4，K-Means 聚类划分四类污染天气模式（清洁型、冬季燃煤型、沙尘型等）。

**6. 机器学习预测**
构建线性回归、随机森林、LightGBM、SVR 四类模型，全部通过网格搜索 + 5 折交叉验证完成超参数调优。

**7. 深度学习预测**
搭建 MLP 多层感知机（128-64-32 结构，Dropout 正则化），完成超参数寻优与对比实验。

**8. 可视化平台**
基于 Vue3 + FastAPI + MySQL 搭建前后端分离平台，包含登录注册、EDA 分析、特征工程、聚类分析、超参数调优、预测分析、在线预测七大页面。

## 模型性能对比

| 模型 | RMSE | MAE | R² |
| :--- | :--- | :--- | :--- |
| 线性回归 | 8.0130 | 4.2396 | 0.9021 |
| 随机森林 | 8.5381 | 5.3492 | 0.8889 |
| LightGBM | 7.9514 | 4.4138 | 0.9036 |
| SVR | 8.6659 | 4.3313 | 0.8855 |
| MLP | 8.5469 | 4.5699 | 0.8886 |

**结论**：
在此数据上，LightGBM 综合性能最优，线性回归次之。数据集强线性特征是模型性能分层核心原因，非线性模型在强线性数据上无法发挥优势。
